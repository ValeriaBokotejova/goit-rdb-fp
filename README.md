# goit-rdb-fp

## 🦠 Final Project: Infectious Disease Data (SQL)

This project includes:

- Creating and using the `pandemic` schema
- Importing and normalizing infectious_cases data to 3NF
- Executing analytical SQL queries (AVG, MIN, MAX, SUM) on `Number_rabies`
- Creating computed columns with date functions (e.g. year difference)
- Defining and using a custom SQL function

All queries were written and tested in MySQL Workbench.
